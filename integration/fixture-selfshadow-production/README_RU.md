# DarkWolf Rend2 · Fixture Self-Shadow Clean Production · Windows x64

Production-пакет использует утверждённую сборку Run `45806188774`. Восстановлено ручное управление собственной тенью корпусов обученных электрических ламп и источников огня. [Утверждённая сборка](https://github.com/jaha2002-stack/iortcw-rend2-build/actions/runs/45806188774)

## Установка

1. Сверьте SHA-256 ZIP с `SHA256SUMS.txt` из файлов релиза.
2. Распакуйте содержимое корневой папки ZIP в отдельную копию установленной игры. Используйте PK3 из своей установки Return to Castle Wolfenstein.
3. Запускайте игру прежним способом. Сохраните прежний `fs_homepath`, чтобы загрузить обученные лампы и профили.

Команды ELSS и IFLC и процедура проверки сохранения масок описаны в `docs/FIXTURE_SELFSHADOW_VERIFICATION_RU.md`. Для отката к предыдущей сборке используйте Win64 ZIP Run `45799720282` и его контрольные суммы.

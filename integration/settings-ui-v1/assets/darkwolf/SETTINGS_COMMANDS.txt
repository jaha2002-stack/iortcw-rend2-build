DarkWolf / ioRTCW Rend2 Settings UI v1

The in-game System -> DARKWOLF GRAPHICS page exposes stable user-facing controls.
Four presets:
  PERFORMANCE
  QUALITY
  HIGH QUALITY
  CINEMATIC

Accepted project inspection commands kept as explicit tools:
  r_staticPromoteInspect
  r_staticPromoteWideInspect

Console-only authoring/destructive commands (intentionally not bound to one-click UI):
  r_staticPromoteLearnCandidate <slot>
  r_staticPromoteBlockCandidate <slot>
  r_staticPromoteClearMap
  r_staticPromoteSyntheticRemove <id>

The QUALITY preset is the conservative baseline. 4096 point shadow maps are
deliberately not used: project A/B already showed little useful gain above 2048.
Shadow-light presets also stop at 3 by default because higher 5-6 values were
associated with instability in runtime testing.

# DarkWolf Rend2 · проверка исправлений производительности · Windows x64

База — Production Run `45990828104`. Список поверхностей растёт при достижении старого предела в 65 536 записей. При `r_finish 0` проверка видимости бликов сохраняет своё чтение глубины, и движок больше не вызывает из-за неё дополнительный `glFinish` перед показом кадра. Поиск теневого кубмапа выполняет меньше повторных вычислений. Настройки графики, шейдеры, игровая логика и ресурсы сохранены. BAT записывает локальную телеметрию производительности.

## Как собрать один сеанс

1. Распакуйте ZIP в отдельную копию рабочей папки игры. Оставьте те же PK3 и профили, с которыми проявляется торможение.
2. Запустите `RUN_DARKWOLF_PERF.bat`. При запросе укажите обычный `fs_homepath` или его копию. Оставьте окно запуска открытым.
3. Загрузите то же сохранение в Escape1 или Factory с прежним графическим профилем. Сразу загрузив карту, пройдите знакомый участок с просадкой и повторите его в том же сеансе. Первый и повторный проходы помогают измерить отдельно построение теней при загрузке карты и скорость обычных кадров. При вылете дождитесь завершения записи.
4. Заархивируйте последнюю папку `capture-…` из `DarkWolf_Performance_Logs` и приложите её целиком. Добавьте название карты и коротко опишите, в какой момент были фриз или вылет. Игровые файлы и сохранения к логам прикладывать не нужно.

`engine.tsv` содержит время кадра, ожидание лимита FPS, фазы ввода, сервера и клиента, состояние памяти Hunk и ошибки движка. `render.tsv` записывает работу CPU, теневые проходы, чтение глубины, максимальный размер списка поверхностей и события `surface_buffer_grow`. `gpu.tsv` содержит время GPU по проходам, если драйвер поддерживает timestamp-запросы. `session.txt`, `memory.tsv`, `gpu-memory.tsv`, `modules.tsv`, `windows-events.tsv` и, при наличии, `faults.bin` помогают связать вылет с завершением процесса, модулем, нарушением доступа или сбросом видеодрайвера. `faults.bin` содержит только коды и адреса исключений. Счётчики видеопамяти снимаются, если Windows предоставляет их для процесса.

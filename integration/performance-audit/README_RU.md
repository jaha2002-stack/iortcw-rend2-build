# DarkWolf Rend2 · диагностика производительности · Windows x64

База — Production Run `45990828104`. В тесте сохранены настройки графики, игровая логика и ресурсы. Дополнительный EXE и Rend2 DLL собраны с таймерами и счётчиками. Настройки эффектов и шейдеры производственной сборки совпадают. Телеметрия пишется на диск при запуске через специальный BAT. Запись кадров и автоматическая отправка данных отсутствуют.

## Как собрать один сеанс

1. Распакуйте ZIP в отдельную копию рабочей папки игры. Оставьте те же PK3 и профили, с которыми проявляется торможение.
2. Запустите `RUN_DARKWOLF_PERF.bat`. При запросе укажите обычный `fs_homepath` или его копию. Оставьте окно запуска открытым.
3. Загрузите проблемное сохранение. Запишите примерно минуту игры с привычными настройками. По возможности захватите спокойный участок, затем ту же сцену с просадкой или фризом. Сеанс можно завершить обычным выходом. При вылете дождитесь сообщения о завершении записи.
4. Заархивируйте последнюю папку `capture-…` из `DarkWolf_Performance_Logs` и приложите её целиком. Добавьте название карты и коротко опишите, в какой момент были фриз или вылет. Игровые файлы и сохранения к логам прикладывать не нужно.

`engine.tsv` содержит время кадра, ожидание лимита FPS, фазы ввода, сервера и клиента, состояние памяти Hunk и ошибки движка. `render.tsv` записывает карту, координаты камеры, параметры рендера, работу CPU и счётчики теневых проходов, чтения глубины и переполнения очередей. `gpu.tsv` содержит время GPU по проходам, если драйвер поддерживает timestamp-запросы. Результаты GPU считываются с задержкой только после готовности. `session.txt`, `memory.tsv`, `gpu-memory.tsv`, `modules.tsv`, `windows-events.tsv` и, при наличии, `faults.bin` помогают связать вылет с завершением процесса, модулем, нарушением доступа или сбросом видеодрайвера. `faults.bin` содержит только коды и адреса исключений. Некоторые исключения могут быть обработаны игрой или драйвером. Счётчики видеопамяти снимает окно запуска через Windows, если счётчики доступны для процесса.

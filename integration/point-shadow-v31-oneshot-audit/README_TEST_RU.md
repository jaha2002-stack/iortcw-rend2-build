# DarkWolf Point Shadow V3.1: автоматический отчёт по Boss1

База: неизменяемый Clean Production #41019985033.
Тестовое продолжение V3 #41194882539.
Предыдущие скриншоты пользователя: D (исключены 0–3636) гигантская тень сохраняется, E (исключены 3637–7273) исчезает.
**Один запуск:** в том же сохранении Boss1 выполните `/exec DW_PS_V31_BOSS1_AUTO.cfg`.

Параметры выбраны автоматически: capture=(-2764,-219,-24), target tolerance=0.25, range=3637..7273.
V31 AutoAudit только фиксирует данные о BSP-кандидатах; НЕ убирает каскадеров, НЕ редактирует глубину/форму тени, НЕ меняет остальные эффекты. Сборка только для отдельной установки.

В консоли должно появиться:
`DW_PS_V31_AUTOREPORT_OK path=dw_ps_v31_boss1_auto.json ...`

В игре в активной записываемой папке (обычно `Main` в игровом каталоге или пользовательский домашний путь RTCW) появится файл `dw_ps_v31_boss1_auto.json`. Найдите его поиском по имени, пришлите сюда — вместо новых десятков ручных тестов. При желании снимок проблемной тени тоже, но A/B/D/E уже загружены.

JSON содержит top-160 поверхностей из выбранного диапазона, **попавших в теневой draw list**, материал, тип, AABB, расстояние до capture origin, оценку углового размера, проверку origin-inside-AABB, сводку по всему диапазону и ограничения достоверности. Отсутствие `AUTOREPORT_OK` означает, что выбранный point-shadow capture не был повторно построен (или кадр не совпал); **отчёт нельзя считать подтверждённым**.

Ни один поверхностный ID ещё не доказан **владельцем пикселя depth cubemap**. Для этого требуется отдельная raster/depth-ownership проверка. Не переносить фильтрацию/телеметрию в Clean Production.

Откат: `/exec DW_PS_V3_A_BASELINE.cfg` (при наличии V3 CFG), затем восстановить оригинальный renderer DLL #41019985033.

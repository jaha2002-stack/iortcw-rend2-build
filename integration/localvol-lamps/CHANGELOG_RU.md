# DarkWolf Rend2 — Local Volumetric Modes 2, 3 и 5

Исправление полос режима 5 принято по результатам игры на сборке Run
45774590836. Режимы 2 и 3 использовали отдельную ветку диспетчеризации
и всё ещё писали слабое рассеяние в общий RGBA8-буфер.

Теперь проходы ламп режимов 2, 3 и 5 используют отдельную половинную
RGBA16F-цель и парные смещения отсчётов вдоль луча. При штатном значении
CVAR используются 36 отсчётов. Сохраняются прежние выбор лампы, цвет и
тени. В режиме 2 cubemap-тени не используются. В режиме 3 сохраняется
требование к доступности cubemap и существующий фильтр теней.
Диспетчеризация обеих веток режима 5 оставляет тот же расчёт луча.

Внутренний флаг применяется только к GLSL-режимам ламп 2 и 3.
Расчёты огня GLSL 5–8, солнечный проход, диагностический режим 1,
прожекторный режим 4, глубинная реконструкция и значения CVAR
по умолчанию сохранены. Прототип R_LoadImage обеспечивает сборку GCC 14.

Патч затрагивает tr_backend.c, tr_local.h, tr_image.c, tr_fbo.c
и glsl/volumetriclocal_fp.glsl в SP/code/rend2. CI восстанавливает
принятый источник Run 43411054498 по коммиту
250669a231dc7bd571b4e2b3405c045f90ba64c1 на базе ioRTCW
438e7d413b5f7277187c35b032eb0ef9093ae778, запускает проверки огня,
управления лампами и GLSL 1.20/1.30/1.50 и выполняет сборку MinGW.

В ZIP заменён только Rend2 DLL. Остальные семь EXE и DLL побитово взяты
из Run 43414829881. Из архива исключены PK3, PK4 и Main/dw_ai.

Проверка в игре для режимов 2 и 3 ожидается. Проверьте полосы при движении
камеры, ясность границ теней в режиме 3 и FPS.

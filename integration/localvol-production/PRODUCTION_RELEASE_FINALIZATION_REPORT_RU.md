## Ограничения

Облачный аудит не запускал игру на Windows, не замерял FPS на реальном GPU и не проверял весь набор кампаний. Приёмка пользователем касается целевого дефекта. Производительность зависит от драйвера и числа ламп. Путь с RGBA8 при отсутствии RGBA16F остаётся из принятой сборки. Для запуска нужны легально приобретённые ресурсы RTCW. Файлы вспомогательной функции локального AI берутся из существующей установки.

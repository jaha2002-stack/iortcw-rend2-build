# DarkWolf Rend2 — Clean Production для Windows x64

Эта версия закрепляет итог испытаний волнообразных полос локального volumetric в режимах 2, 3 и 5. Бинарники, шейдеры, CFG и BAT побитово совпадают со сборкой, проверенной в игре. В комплекте восемь EXE/DLL, 19 CFG и три BAT.

## Установка и запуск

1. Сделайте копию рабочей установки Return to Castle Wolfenstein и сохраните резервную копию настроек и сохранений.
2. Распакуйте содержимое верхней папки архива в корень тестовой установки. Оставьте свои игровые PK3/PK4 в `Main`, а для локального AI-восстановления текстур сохраните существующий `Main/dw_ai/`.
3. Запускайте игру прежним способом и с прежним `fs_homepath`. Для нового профиля в комплекте есть `RUN_DARKWOLF_IFLC_CLEAN.bat`. Его можно вызвать с полным путём до существующего homepath первым аргументом.
4. Для Local Volumetric используйте Rend2 с HDR, `r_volumetricLocal 1` и режим 2, 3 или 5. Встроенные шейдеры используются при `r_externalGLSL 0`.

Режим 2 рассчитан на лампу без cubemap-теней, режим 3 использует cubemap доступного источника, а режим 5 поддерживает несколько ламп. Если используются внешние изменённые шейдеры, результаты могут отличаться.

## Состав и проверка

`PRODUCTION_MANIFEST.json` описывает точные входные файлы и версию. `SHA256SUMS.txt` содержит контрольные суммы содержимого ZIP. На странице релиза опубликованы контрольная сумма самого архива, итоговый отчёт и точный снимок исходников для восстановления. Лицензии находятся в `LICENCE.md` и `docs/licenses/`. Справка по IFLC сохранена в `docs/IFLC_COMMANDS_RU.md`.

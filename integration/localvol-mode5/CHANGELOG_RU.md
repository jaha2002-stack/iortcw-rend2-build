# DarkWolf Rend2 — исправление Local Volumetric Mode 5

База полного комплекта — GitHub Actions Run 43414829881, артефакт 14030454225.
Исходники принятого рендерера восстановлены через workflow Run 43411054498
на коммите 250669a231dc7bd571b4e2b3405c045f90ba64c1. Ревизия ioRTCW
438e7d413b5f7277187c35b032eb0ef9093ae778.

- Лампы публичного режима 5 используют отдельный половинный RGBA16F-буфер.
  Слабое рассеяние сохраняет точность до сложения в HDR. Общая RGBA8-цель
  остаётся резервной при отсутствии поддержки этого буфера.
- Парные смещения отсчётов вдоль луча уменьшают коррелированные полосы.
  По умолчанию raymarch лампы использует 36 отсчётов вместо 24.
- В tr_local.h добавлен прототип существующей R_LoadImage для GCC 14.
- Сохранены алгоритмы солнца, огня и других режимов. Значения CVAR по
  умолчанию, готовые CFG и BAT взяты из исходной сборки.

Патч меняет tr_backend.c, tr_local.h, tr_image.c, tr_fbo.c и
glsl/volumetriclocal_fp.glsl в SP/code/rend2. CI применяет патч поверх
закреплённого источника, повторяет тесты огня, управления лампами и GLSL
1.20/1.30/1.50, затем собирает Win64 через существующий рецепт MinGW.

В ZIP заменён только Rend2 DLL. Остальные семь EXE и DLL побитово взяты
из Run 43414829881. ZIP исключает PK3, PK4 и Main/dw_ai.

Проверка в игре ожидается. Сравните полосы в том же ракурсе с профилем
Vivid, движение камеры, FPS, границы света вокруг балок, работу
dw_lamp_toggle, огонь и солнечные лучи.

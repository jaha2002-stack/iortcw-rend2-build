## Ограничения и риски

Игровая приёмка охватывает целевой дефект. В облаке не проведены полный прогон кампаний, повторная визуальная проверка на Windows или замеры FPS на игровом GPU. Детали без записи глубины могут сохранять иные виды алиасинга. Смешивание использует два слоя глубины, а без MSAA применяется приближённый метод. Производительность зависит от драйвера, MSAA и числа краёв со смешанным покрытием. Для запуска нужны собственные легально приобретённые ресурсы RTCW.

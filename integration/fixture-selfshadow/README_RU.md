# DarkWolf Rend2 · проверка собственной тени светильников

Тестовая сборка Win64 основана на утверждённом Run `45799720282`. Используйте PK3 из своей установки RTCW.

## Установка

В отдельной копии установленной игры распакуйте содержимое корневой папки ZIP. Для сравнения с Production можно заменить только `renderer_sp_rend2_x64.dll`, предварительно сохранив исходную DLL. Запускайте игру тем же способом и с тем же `fs_homepath`, чтобы загрузились ваши обученные лампы и сохранённые профили. Для теста с отдельным профилем можно скопировать текущий homepath.

## Проверка в игре

1. **Обученная электрическая лампа.** Установите `/r_dwElectricLightControl 1`. Выполните `/dw_el_select`, при нескольких кандидатах выберите нужную лампу через `/dw_el_next`. Проверьте результат через `/dw_el_info`. Наведитесь на корпус, выполните `/dw_el_self_pick`, затем `/dw_el_set selfshadow 0`. Проверьте, что число `manualSeeds` выросло и исчезла именно тень корпуса от выбранной лампы. Для сравнения используйте `/dw_el_set selfshadow 1` и вновь `0`. Сохраните через `/dw_el_save` и проверьте после перезапуска карты.
2. **Факел или огненная лампа.** Установите `/r_dwFireLightControl 1`. Выполните `/dw_fl_select` и при необходимости `/dw_fl_next`. Для источника с маршрутом `VOLUME_ONLY` выполните `/dw_fl_set enabled 1` и `/dw_fl_save`. Наведитесь на твёрдую часть корпуса, выполните `/dw_fl_self_pick`, `/dw_fl_set selfshadow 0`, `/dw_fl_info`. Сохраните через `/dw_fl_save` и проверьте повторную загрузку. Если корпус состоит из нескольких несвязанных частей, каждую можно выбрать отдельно.
3. **Escape1.** Повторите включение и выключение ранее проблемных ламп своим обычным способом. Проверьте, что при движении и развороте камеры соседи не мигают. Убедитесь, что корпус остаётся видимым, а стены и двери продолжают отбрасывать тень от выбранного и соседних светильников.
4. **Возврат.** `/dw_el_set selfshadow auto` и `/dw_fl_set selfshadow auto` возвращают автоматическую политику. Для полного A/B верните исходную DLL.

Инструменты меняют создаваемую рендерером тень выбранного источника. Запечённая тень в lightmap BSP требует изменения самой карты. Если тень останется, для диагностики сохраните название карты, место, вывод `dw_el_info` или `dw_fl_info` и сообщение `self_pick`. Для этой сборки игровой тест на Windows выполняется пользователем.

# DarkWolf IFLC V1.1 — локальное самозатенение крепления

База: #41408153237; IFLC V1: #41691075610. Статус этого пакета — TEST_CANDIDATE. Сборка не заменяет визуальную приёмку; результаты Crypt1/Crypt2 публикуются отдельно.

## Изменение V1.1

Для явно включённого через IFLC огня без собственного Direct (`VOLUME_ONLY`, `enabled=1`) определяется небольшое связное крепление возле геометрии пламени. Если найдена однозначная опорная стена и компактная трёхмерная группа граней чаши/крепления, только эти грани исключаются из двух карт теней СВОЕГО нового Direct DLight. Так устраняется дополнительный большой силуэт собственного крепления при сохранении других теней и прямого света.

Это локальная политика исключения самозатенения, а не вычисление физически точного площадного источника. Положение и радиус источника не сдвигаются. Стена, в том числе её небольшие соплоскостные фрагменты, остаётся препятствием; двери, модели, персонажи и соседние предметы не исключаются. От других источников то же крепление продолжает отбрасывать тень. Исходные native/promoted источники и synthetic FireVol не получают эту новую политику.

В алгоритме нет имён карт, ID поверхностей или конкретных материалов. Он применяется на любой карте к подтверждённому геометрическому классу, а не ко всем лампам вслепую. Напольные чаши без опорной стены, большие огни, неоднозначная геометрия, неподтверждённые соединения и переполнение списка сохраняют прежние тени. Отдельно проверяются другие типы ламп/факелов Crypt1 и Crypt2 на отсутствие регрессии.

Ключ world-occlusion кэша теперь включает политику собственного крепления: карта глубины без исключений не может подменить карту с исключениями при одинаковом положении света. PCF4x4 V1.4, GLSL, FireVol, CSM, глобальные бюджеты и формат профилей V1 не меняются. Новых production cvar нет.

## Установка и использование

Закройте игру, сохраните прежнюю DLL и замените только `renderer_sp_rend2_x64.dll` рядом с EXE рабочей базы. Игровые EXE/modules/ресурсы/настройки остаются прежними. Сохранённые `firelights/<map>.iflc` совместимы.

```cfg
/r_dwFireLightControl 1
/dw_fl_select
/dw_fl_info
```

Для `route=VOLUME_ONLY`:

```cfg
/dw_fl_set enabled 1
/dw_fl_set direct 1.80
/dw_fl_set radius 1.30
/dw_fl_set volume 1.00
/dw_fl_save
```

`dw_fl_info` показывает `fixtureSelfCasters`: количество распознанных граней собственного крепления. Ноль означает, что узкая геометрическая проверка не подтвердила подходящую группу; это не означает выключение всех теней. Автоматическая коррекция действует только на собственный opt-in Direct, когда он активен.

Для отключения IFLC используйте `r_dwFireLightControl 0`. Для возврата к предыдущему рендереру восстановите резервную DLL. Полный список команд находится в `README_COMMANDS_V1_RU.md`.

## Проверка

CPU-тесты выполняют настоящий C-код и проверяют в том числе поворот/перенос крепления, защиту стены и её фрагментов, чужие источники, CSM/FireVol, модели и неоднозначность. Изолированная native TestLab имеет тестовый bypass и read-only audit; этих команд нет в выдаваемой Windows DLL. Приёмка изображений и целевой Windows GPU — отдельные этапы; успешный CI сам по себе не является визуальным PASS.

# DarkWolf Rend2 · сглаживание силуэта оружия от первого лица

Тестовая сборка Win64 основана на одобренном исправлении LocalVol из Run 45953757143. Установите архив в отдельную копию игры или замените в ней `renderer_sp_rend2_x64.dll`. Используйте прежние игровые ресурсы, сохранения и настройки.

При HDR и MSAA рендерер выделяет покрытие видимой геометрии оружия от первого лица и сглаживает цвет только в смешанных пикселях вдоль края. В обработке участвуют непрозрачные поверхности с записью глубины. Фильтр использует соседние пиксели в пределах одного шага. У очень тонких деталей без выраженного направления границы сохраняется обычный результат MSAA.

## Проверка

1. Загрузите ту же сцену Escape1 и оставьте обычные HDR и MSAA ×8.
2. Сравните мушку, прорезь целика и диагональ ствольной коробки с `/r_viewmodelEdgeAA 1` и `/r_viewmodelEdgeAA 0`. Перезапуск видео для сравнения не нужен. Двигайтесь и поворачивайте камеру одинаково в обоих случаях.
3. Сравните FPS, затем верните `/r_viewmodelEdgeAA 1`. У решётки проверьте уже утверждённое сглаживание светом лампы при `r_volumetricLocal 1`.

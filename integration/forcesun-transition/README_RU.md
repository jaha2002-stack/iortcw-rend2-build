# DarkWolf Rend2 · r_forceSun и точечный свет · тест Windows x64

Комплект основан на Fixture Self-Shadow Clean Production, Run `45818977157`. Включена правка каскадных теней из Run `45823631698`. Из файлов игры заменена `renderer_sp_rend2_x64.dll`. [Базовый Production Release](https://github.com/jaha2002-stack/iortcw-rend2-build/releases/tag/darkwolf-fixture-selfshadow-clean-production-20261126)

## Исправление

Проход материала и проход точечного света могут использовать одну GLSL-программу. Второй проход отключал отражения, но сохранял параметры непрямого света предыдущего материала. При активном непрямом освещении программа могла прочитать RGB-закодированную глубину кубической карты точечной тени как цвет окружения. Теперь этот проход сбрасывает оба параметра перед выборкой кубической карты. Точечные тени и непрямое освещение основного прохода продолжают работать.

## Проверка

1. Сверьте SHA-256 по файлу `.zip.sha256`. Скопируйте новую DLL в отдельную копию игры или распакуйте весь комплект поверх неё. Сохраните исходную DLL для отката. Используйте прежний `fs_homepath` и свои PK3, чтобы сохранить профиль и базовые ресурсы сцены.
2. На той же стене Escape1 повторите `/r_forceSun 1` → `/r_forceSun 0` → `/r_forceSun 1` при своих обычных настройках и осмотрите стену при повороте камеры.
3. Сверьте, что свет и тени от ближайшей лампы сохраняются в обоих режимах. Команды ELSS и IFLC приведены в `docs/FIXTURE_SELFSHADOW_VERIFICATION_RU.md`.

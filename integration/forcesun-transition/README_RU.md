# DarkWolf Rend2 · переключение r_forceSun · тест Windows x64

База теста — Fixture Self-Shadow Clean Production, Run `45818977157`. В архиве заменена `renderer_sp_rend2_x64.dll`. Сравнение основных файлов, история предыдущих изменений и SHA-256 приведены в архиве. [Базовый Production Release](https://github.com/jaha2002-stack/iortcw-rend2-build/releases/tag/darkwolf-fixture-selfshadow-clean-production-20261126)

## Что исправлено

Принудительное солнце, солнце карты и его объёмный эффект записывали глубину в общие текстуры каскадных теней. При смене источника старый кэш мог оставаться действительным, хотя текстуру уже перезаписал другой источник. Кроме того, проход неба через портал мог читать солнечные карты из чужого кадра. Теперь при смене источника каскады обновляются заново, а команды отрисовки получают отметку готовности только для своего кадра. Режим `0` убирает принудительное солнце и сохраняет штатное солнце карты, если оно задано.

## Установка и проверка

1. Сверьте SHA-256 ZIP по приложенному файлу `.zip.sha256`. Распакуйте содержимое корневой папки в отдельную копию игры. Используйте PK3 из своей установки RTCW. Можно заменить только DLL Rend2. Сохраните исходную DLL для отката, а также используйте прежний `fs_homepath` для загрузки обученных ламп и профилей.
2. В сцене, где возникали помехи, выполните `/r_forceSun 1`, затем `/r_forceSun 0`. Оставаясь в той же сцене, поверните камеру и повторите `1 → 0 → 1` без `/vid_restart`. Проверьте стены, пол и границы теней.
3. При выставленном `0` выполните `/vid_restart`, повторите маршрут и проверьте, что помехи не зависят от перезапуска. На карте с собственным солнцем проверьте его тени. На улице при `r_forceSun 1` проверьте сглаживание объёмного солнечного света.
4. Для проверки остальных исправлений сравните лучи местных ламп в режимах 2, 3 и 5, объёмный огонь и ручные маски ELSS и IFLC со стабильной сборкой. Команды для масок приведены в `docs/FIXTURE_SELFSHADOW_VERIFICATION_RU.md`.

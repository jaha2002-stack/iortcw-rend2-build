# DarkWolf Rend2 — Sun Volumetric Silhouette AA, Win64 Test

База — утверждённый Run 45778124832 и Clean Production с тегом
`darkwolf-localvol-modes-235-clean-production-20261126`. В ZIP меняется
только `renderer_sp_rend2_x64.dll`. EXE, игровые DLL, CFG и BAT взяты
побитово из Clean Production. Для запуска используйте свои игровые ресурсы.

## Установка и проверка

Распакуйте содержимое верхней папки ZIP в отдельную копию рабочей
установки. Сохраните прежний homepath, CFG, сохранения и PK3/PK4.
Проверьте, что включены Rend2 и HDR. Для сравнения встроенных шейдеров
задайте `r_externalGLSL 0` и выполните `vid_restart`, если ранее
пользовались внешними GLSL.

В том же ракурсе сравните `r_volumetricSun 1` до и после замены DLL.
Отдельно сравните с `r_volumetricSun 0`, эта переменная требует
`vid_restart`. Для парного A/B без перезапуска используйте
`r_volumetricSunMode 0/1` при включённом `r_volumetricSun`.

1. Каменные крыши и трубы на фоне неба, окна и разрушенная кладка.
2. Металлический парапет, балки и тонкие ограды на фоне дальней стены.
3. Силуэт оружия, движущиеся модели, медленный поворот камеры и FPS.

При возможности сравните MSAA 4× и MSAA 0 с `vid_restart` между ними.
Проверьте, что SunVol сохраняет форму лучей и тени, а Local Volumetric
2, 3, 5 и огонь выглядят как в Clean Production.

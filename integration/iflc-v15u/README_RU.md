# DarkWolf IFLC V1.5 Universal Manual Self-Shadow

Узкая доработка успешной V1.5 Run #41827953550.

AUTO не меняется: автоматическое определение корпуса по-прежнему требует
надёжную flame-геометрию.

MANUAL `dw_fl_self_pick` теперь использует уже выбранный `dw_fl_select`
стабильный owner и его origin. Поэтому ручной режим не зависит от наличия,
компактности или однозначности BSP flame-bounds. Один и тот же код работает для
NATIVE_FIRE, PROMOTED_FIRE и VOLUME_ONLY; отдельной карты/модели/номера факела в
алгоритме нет.

Безопасность сохранена:
- неоднозначный physical owner по-прежнему запрещён;
- flame shaders нельзя выбрать как корпус;
- стена/пол/потолок и совпадающие архитектурные плоскости защищены;
- группа растёт только по реальному контакту mesh;
- локальный размер/дистанция ограничены;
- до 8 seed позволяет добавить несколько несвязанных частей корпуса.

Команды:
1. `/r_dwFireLightControl 1`
2. прицел на огонь: `/dw_fl_select`
3. прицел на конкретную часть корпуса: `/dw_fl_self_pick`
4. повторить пункт 3 для другой несвязанной части, если нужно
5. `/dw_fl_info` -> manualSeeds>=1, ownBodySurfaces>=1
6. `/dw_fl_set selfshadow 0`
7. `/dw_fl_save`

`selfshadow auto` возвращает принятую автоматическую политику.
`selfshadow 1` возвращает исходную собственную тень.

# DarkWolf Individual Fire Light Control — IFLC V1

Экспериментальный инструмент индивидуального управления стационарными огненными источниками. База: **Run #41408153237**, commit `6fd61c7bd4e6a1c23c549c93d237f2204c9d3d89`. Это отдельный тестовый кандидат; исходная база не заменяется автоматически.

## Установка

Закройте игру, сохраните копию прежнего `renderer_sp_rend2_x64.dll` и замените только этот файл рядом с вашим игровым EXE. EXE, `cgame`, `qagame`, игровые ресурсы и ранее настроенные CFG остаются от вашей рабочей сборки #41408153237. Файлы `DW_IFLC_V1_ENABLE.cfg` и `DW_IFLC_V1_DISABLE.cfg` при желании положите в `Main`.

## Начало работы

Инструмент по умолчанию выключен. В консоли включите его и наведите прицел непосредственно на пламя нужного факела:

```cfg
/r_dwFireLightControl 1
/dw_fl_select
/dw_fl_info
```

Команда сообщает постоянный ключ источника и его маршрут. Если в прицеле несколько подходящих объектов, автоматического выбора нет: команда `dw_fl_next` явно переключает кандидатов. При неоднозначной связи между самой геометрией пламени и несколькими источниками редактирование блокируется.

Для начала можно использовать умеренные значения:

```cfg
/dw_fl_set direct 1.80
/dw_fl_set radius 1.30
/dw_fl_set volume 1.00
/dw_fl_save
```

Все команды настройки относятся только к текущему выбранному физическому источнику. Перейдите к следующему факелу, снова выполните `dw_fl_select` и задайте ему собственные значения.

## Команды и параметры

| Команда | Назначение |
|---|---|
| `dw_fl_select` | Выбрать видимый факел под прицелом, до 512 игровых единиц, с проверкой препятствий. |
| `dw_fl_next` | Явно выбрать следующего кандидата из последнего списка выбора. |
| `dw_fl_info` | Показать постоянный ключ, маршрут света, текущие множители и состояние профиля. |
| `dw_fl_set direct 0..3` | Мощность прямого освещения стен, пола и моделей. `1` — исходная, `2` — двойная, `0` — нулевой прямой вклад. |
| `dw_fl_set radius 0.25..2` | Дальность прямого света относительно исходного радиуса. Изменённый радиус ограничен 512 единицами; профиль с `radius=1` сохраняет исходный радиус. |
| `dw_fl_set volume 0..3` | Независимая сила Fire Volumetric. `0` убирает объёмный вклад данного огня, `1` сохраняет исходный. |
| `dw_fl_set color R G B` | Оттенок прямого света, каждый канал 0..1. Цвет нормализуется к исходной яркости; мощность задаёт `direct`. На текстуру пламени и цвет FireVol не влияет. |
| `dw_fl_set enabled 0/1` | Только для `VOLUME_ONLY`: явное разрешение отдельного настоящего DLight. Для существующих native/promoted источников не используется. |
| `dw_fl_reset` | Удалить профиль выбранного источника и вернуть его базовое поведение. |
| `dw_fl_save` | Сохранить изменения текущей карты. |
| `dw_fl_reload` | Загрузить последнее сохранение; отклонить повреждённые или чужие профили. |
| `dw_fl_list` | Показать изменённые источники текущей карты. |
| `r_dwFireLightControl 0` | Отключить все IFLC-изменения без удаления файлов профилей. |

Если указан `route=VOLUME_ONLY`, видимый огонь сам по себе прежде не создавал прямой DLight. Для подсветки окружающих поверхностей дополнительно выполните:

```cfg
/dw_fl_set enabled 1
/dw_fl_set direct 1.80
/dw_fl_set radius 1.30
/dw_fl_save
```

Новый свет требует включённых глобальных DLight, режима `r_dlightMode 2`, world containment и свободного места в штатном лимите. При отказе `dw_fl_info` сообщает причину. Существующие источники не вытесняются ради нового.

## Сохранение и возврат

Профиль записывается в `firelights/<имя_карты>.iflc` через игровую файловую систему. Фактическая папка зависит от `fs_homepath`/`fs_game`. Файл привязан к отпечатку BSP: профиль от изменённой версии карты не применяется. Для защиты записи проверяются временная копия, резервная копия предыдущего файла и итоговый файл; атомарная операция переименования недоступна в существующем renderer API.

Без `dw_fl_save` изменения существуют только в текущем сеансе карты. `dw_fl_reset` также нужно сохранить, если сброс должен пережить перезапуск. Для возврата ко всей исходной сцене достаточно `r_dwFireLightControl 0`; для возврата к исходному рендереру — восстановить сохранённую DLL.

## Границы V1

Инструмент не меняет яркость самой анимированной текстуры пламени, амплитуду мерцания, запечённый свет, экспозицию, Bloom или глобальные настройки. Мерцание native-источника сохраняется. Бюджеты остаются **32 DLight и 3 динамических теневых слота**: несколько факелов могут освещать комнату, даже когда не каждому выделена отдельная динамическая карта теней.

Изменение радиуса меняет физическую область освещения и может потребовать обновления карты окклюзии. Геометрический радиус FireVol берётся из исходного источника, но при использовании настоящей карты тени нормализация глубины обязана соответствовать её реальному радиусу. Полную независимость всех пикселей объёма от изменения радиуса V1 не обещает.

## Проверки

CI отдельно публикует доказательство восстановления 1647 исходных файлов принятой базы, перечень изменённых файлов, CPU-тесты настоящего C-кода, Win64-сборку и результаты игрового TestLab. Захваченные кадры Crypt1 получаются из реальной игры под Linux/Mesa; это не тест производительности или визуальная приёмка на вашем Windows/GPU.

Статус успешной компиляции не означает визуальный PASS. Итоговый статус игровых проверок следует читать в отдельном артефакте `DW-IFLC-V1-Tests-and-Crypt1-Evidence` и сопроводительном отчёте.
